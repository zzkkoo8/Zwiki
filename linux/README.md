# Linux

记录 Linux 系统安装、配置、运维、性能分析和故障排查文章。

## 收录范围

- 系统安装、启动与内核
- 用户、权限和认证
- systemd、进程与服务
- 磁盘、文件系统、LVM 和 I/O
- 网络、DNS、SSH 和防火墙
- 日志、监控、性能和安全加固
- 软件包管理、Shell 命令与脚本
- 系统故障定位与恢复

## 文章归类

文章直接存放在本目录；同一主题积累到三篇以上时，再建立对应子目录。例如磁盘类文章可逐步整理到 `storage/`，故障文章可整理到 `troubleshooting/`。

新增文章优先使用[通用技术文章模板](../templates/technical-article.md)或[故障排查模板](../templates/troubleshooting.md)。
