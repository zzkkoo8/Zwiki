## 唯一事实源

项目代码、规格和设计文档的权威源位于：

- GitHub：<https://github.com/zzkkoo8/xmg-qa2>

Zwiki 中的页面属于**自动生成的阅读镜像**，不作为 xmg-qa2 设计和开发的事实源。修改设计时必须先修改 xmg-qa2 原仓库；Zwiki 的 `.github/workflows/sync-xmg-qa2.yml` 默认每 15 分钟检查一次源文档，发现变化后自动更新镜像并提交到 Zwiki `main`，随后由 GitBook Git Sync 发布。

如需立即同步，可在 GitHub Actions 中手动运行 `Sync xmg-qa2 docs`。
