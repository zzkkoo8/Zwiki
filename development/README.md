## 使用原则

- 优先记录可重复执行、可验证、可回退的开发流程。
- 技术栈优先选择社区主流、文档完善、AI 生成质量稳定的方案。
- 示例必须包含验收标准；涉及变更时必须说明失败判定与回退方式。
- AI 生成代码不能替代必要的 Review、自动化测试与 CI 验收。
