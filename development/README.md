# 开发

本分类统一收纳软件开发相关内容，避免把“开发方法”和“开发工具”拆成多个一级目录。

## 内容入口

- [AI 全栈开发规范（FDE）](ai-fullstack-workflow.md)：Coding Agent 前后端开发流程、阶段门禁、测试与交付规范。
- [工具平台](tools/README.md)：GitHub、GitBook、Vercel、CI/CD 等开发与发布平台。
- [开发资源](resources/dev-toolbox.md)：精选高热开源项目、插件与 Skills，直接辅助设计、前端、后端、测试和 AI Coding。

## 收录原则

- 开发方法、工程规范、AI Coding 工作流统一放在 `development/`。
- 具体工具和发布平台放在 `development/tools/`。
- 可直接复用的开源项目、插件和 Skills 放在 `development/resources/`。
- 优先收录社区主流、持续维护、文档成熟、AI 容易正确使用的项目。
- 同一主题只保留少量主流选择，避免把 Zwiki 变成无筛选的链接大全。
