# 基建

收录硬件、操作系统、网络和基础服务相关的基础设施知识。

## 分类

- [硬件](hardware/README.md)：服务器、CPU、内存、磁盘、RAID、网卡、BMC 与硬件故障诊断。
- [系统](system/README.md)：操作系统安装、内核、存储、权限、服务、安全加固与故障恢复。
- [网络](network/README.md)：协议、路由交换、流量路径、网络设备与网络故障排查。
- [基础服务](services/README.md)：DNS、NTP、SSH、Nginx、HAProxy、Keepalived、NFS 等通用基础服务。

容器平台继续归入 Zwiki 的“容器与云原生”分类，不放在本目录。
