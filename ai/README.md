# AI

本分类收纳围绕 AI 工具、模型、Agent、Vibe Coding、Skills、插件、模型接入和提示词的资源与实践。

## 内容入口

- [AI Coding](ai-coding.md)：Vibe Coding、Coding Agent、Codex、Claude Code、Cursor 等 AI 编程工具和工作流。
- [Skills 与插件](skills-plugins.md)：Agent Skills、插件、MCP 及可复用工作流。
- [模型与接入](model-access.md)：模型平台、API Key / Token 的合法获取、环境变量配置和安全管理。
- [提示词](prompting.md)：可复用提示词结构、开发提示词、审计提示词和 Prompt Engineering 方法。
- [AI 资源](resources.md)：官方文档、Cookbook、GitHub 项目和高质量学习资源。

## 与“开发”的边界

- `development/` 负责软件工程本身：前端、后端、测试、发布、工程规范和项目交付。
- `ai/` 负责 AI 能力和工具：模型、Agent、Vibe Coding、Skills、插件、MCP、Prompt 和模型接入。
- [AI 全栈开发规范（FDE）](../development/ai-fullstack-workflow.md) 继续归“开发”，因为它的目标是稳定完成前后端项目，而不是介绍某一个 AI 工具。
- 某个资源同时涉及开发和 AI 时，以“主要解决什么问题”为准，只保留一个权威页面，其他位置使用链接引用，避免重复维护。

## 安全原则

- 只记录 API Key、Token 的申请和配置方法，不提交真实凭据。
- 示例统一使用环境变量或占位符。
- 优先引用官方文档、官方仓库和持续维护的项目。
